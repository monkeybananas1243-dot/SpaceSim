# **This is a log for my space simulations.**

## **Code Display**
The actual space sim is called 'gravity_v2'.
To see my other efforts in black holes, see 'blackhole_v1.py.

- ### *How to make your own changes*
    In order to change the planets, scroll down to the spot where there is a bold comment which says "Planets".

  You can then choose to make your own planets (see 'gravity_planets.txt' for the structure), or choose from some presets I made.

    If you want to remove a planet, a easier way is to remove the 'planets.append(planet_here)'.
